# 바른혈압 검색 키워드 지도

검색창에 사람들이 실제로 치는 말을 묶어, 어느 페이지가 그 검색어를 맡는지 정리한 표입니다. 매일 발행할 때와 기존 글을 고칠 때 이 표를 기준으로 합니다. (작성 2026-11-27)

## 원칙

1. **한 검색어는 한 페이지가 맡는다.** 같은 검색어를 두 글이 노리면 서로 순위를 깎아 먹습니다. 새 주제가 표의 기존 페이지와 겹치면 새 글을 쓰지 말고 기존 글을 보강합니다.
2. **제목 앞에 검색어를 그대로 둔다.** `대표 검색어 — 부제` 형식. 예: `혈압 정상수치 표 — 수축기·이완기 기준과 수치별 의미`
3. **요약 첫 문장에 답을 쓴다.** 검색 결과 설명과 AI 검색 답변에 그대로 인용됩니다.
4. **자주 묻는 질문은 검색 문장 그대로.** “○○ 정상인가요?”, “○○ 먹어도 되나요?”처럼 물음표로 끝냅니다.
5. **숫자는 연도와 출처를 붙인다.** AI 검색은 출처가 분명한 문장을 인용합니다.

## 네이버·구글·AI 검색에서 달리 볼 것

- **네이버**: 제목·설명·대표 이미지(og)를 그대로 씁니다. 페이지마다 공유 이미지가 자동으로 만들어집니다. 새 글은 서치어드바이저 ‘웹 페이지 수집’ 요청을 하면 빨리 반영됩니다(사람이 직접).
- **구글**: 구조화 데이터(Article·FAQ·Recipe·Breadcrumb)와 사이트맵의 수정일을 봅니다. 사이트맵 수정일은 글의 실제 수정일로 자동 기록됩니다.
- **AI 검색(ChatGPT·Perplexity·Gemini 등)**: `/llms.txt`, `/llms-full.txt`에 글 목록과 요약·질문·답이 매일 자동으로 갱신됩니다. 출처와 연도가 붙은 짧은 문장이 인용되기 쉽습니다.
